`install.emailRouting.worker` names the Worker of `install.workers` that receives an app's mail (`emailRoutingWorkerProblems`; `emailScriptName` gives its installed name, `installedScriptNames` every Worker name of an install). `{{emailDomain}}` and `{{emailZoneId}}` are placeholders for the zone an app with `install.emailRouting` receives email for, in var defaults, wrangler config vars, service binding props and post-install notes, refused in an entry without `install.emailRouting` (`EMAIL_PLACEHOLDERS`, `usesEmailPlaceholders`); placeholders in a JSON value's keys are filled in too (`mapJsonText`, `jsonTexts`), and an entry that writes any placeholder in an object key of a JSON var or of service binding props must list `email-placeholders` in `requires` (`placeholderInJsonKey`, `jsonKeys`), since older managers fill in values only. `resources.hyperdrive[binding].caching` turns Hyperdrive query caching on or off. Each comes with a `requires` value naming the manager feature, `email-worker`, `email-placeholders` and `hyperdrive-caching`, which the catalog checks require where the field or placeholder is used (`managerFeatureProblems`), so managers from before them leave such entries out; a revision may add `email-placeholders`.
