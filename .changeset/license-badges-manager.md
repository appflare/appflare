Catalog cards and app pages show each app's license as its repository declares it: the id in a neutral badge, a muted "Source-available" before source-available licenses (BUSL, FSL, PolyForm, Elastic, SSPL, or any license with a note, which the tooltip shows), and "No license" in the warning tone for a repository without one. The app page adds a line on what the license allows and links a custom license file at the pinned commit. The catalog gains a license filter: any, open source, source-available, or no license. Apps are never hidden for their license.
