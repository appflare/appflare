The install form and an app's settings now look and behave alike. A generated secret in an app's settings gets a new value from the small refresh button in its "Generated" badge, as in the install form, instead of a separate Regenerate button. The settings form's groups and the install form's Address use the same headings as the install form's other groups, a secret marked "Will be removed" has a red error badge, and two notices lost their trailing full stop. The boxes in the install form share one recessed look with a hairline edge, and the Optional settings row and the domain picker show the same focus ring as other buttons. When the address tray cuts a long reason short, the whole reason now shows in Appflare's own tooltip below the tray, where it no longer covers the name you are typing, instead of the browser's; a reason that fits has no tooltip. Password managers no longer offer to fill or save a generated secret's field, and the app token fields no longer keep what you typed in the page's markup. Screen readers now announce a verified or connected Cloudflare token and a stored app token when the message appears, and announce each token error once, as an alert. A verified token shows as a success rather than as information.
