On an Appflare connected with Cloudflare sign-in, "What this account can run" no longer talks about a token. Its last row, Sign-in permissions, is ready when you allowed every permission Appflare asks for. If one is missing, the row and Home's Needs attention name it and offer Reconnect Cloudflare. The other rows say the same when Cloudflare refuses a check, and the Workers plan row explains that Cloudflare sign-in cannot share the plan, so you choose it. Appflare connected with an API token shows the rows as before.
