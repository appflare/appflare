Screen readers now announce the error a form or dialog shows when something fails, as it appears. Before, only a few sign-in and setup errors were announced. An error on the sign-in and password screens now looks like an error anywhere else in the manager. App icons sit on a white tile, so a dark icon stays visible in dark mode. The sidebar's collapse and expand buttons show the manager's own tooltip instead of the browser's, and Sign out is no longer drawn in red, since it removes nothing.
