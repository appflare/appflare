The first public release of Appflare's typed client for the Cloudflare REST API endpoints it uses, among them Workers, D1, KV, R2, Queues, Containers, custom domains and Access. It runs in Workers and in Node, and can check what an account and its plan allow before an install starts. It can also update an Access application in place, for example to move it to another hostname.
