Your account now has one section, "What this account can run", in place of the onboarding checklist and the account capabilities card. A bar shows how many things are ready, counting only what the account's plan can have. There is one row each for the Workers plan, the workers.dev address, R2 storage, a domain, Email Routing, Analytics Engine, Zero Trust, sandbox builds and the token's permissions. Each row says in a sentence why apps need it and shows Ready, Needs action, Not set up, Paid plan only or Could not check. "Needs action" is only for something an installed app needs; anything else that is off reads "Not set up", so a new account is not a wall of warnings. A row that is off has one button: "Turn on in Cloudflare" opens the right dashboard page, "Edit token in Cloudflare" opens the token's page, "Choose plan" lets an admin state the Workers plan while Appflare cannot read it, and "Set up" opens Building apps. A row Appflare could not check has no button; "Check again" reads it again. "Details" shows what Appflare found and whether it detected it or you set it, when it checked, why a check failed, and how many catalog apps use it. "Re-check" is now "Check again". The last setup step shows the same rows. Old links to the checklist still land on the new section.
