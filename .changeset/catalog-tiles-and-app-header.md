Catalog tiles stand upright again: the icon on top, then the name, a pitch of at most two lines, and one line with the plan, the GitHub stars and the Get or Manage button. Tiles are a fixed width with a clear gap between them in each row, and "All apps" uses the same tiles in a grid.

On an app's page the button reads "Install" and is a normal button with its label centred, with nothing under it except a member's reason. The stat strip keeps every value on one line, so a long version no longer makes the row tall: a build from an untagged commit shows its day ("Sep 21"), a release shows its version, and the full value is in the tooltip. "What it needs on your account" drops its tooltips; a need the account lacks ends in a link to the Cloudflare dashboard page that fixes it ("Upgrade", "Turn on", "Add a domain"). In "Settings you will choose", a setting with help text gets a small "?" that shows the help and the setting's technical name.
