Dismissing the "Clean up the deploy copy" card or hiding a sponsored catalog item now takes it away at once and saves in the background, instead of waiting for the server with a spinning button. If the save fails, the item comes back with a short "Could not save; shown again" toast.

The home page no longer shows an "Anonymous usage data is on" banner. Usage data stays on by default; Settings, Usage data and the docs describe what is sent and how to turn it off.
