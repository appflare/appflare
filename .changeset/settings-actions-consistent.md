The "Update" button on the sidebar's Appflare card, and its "Try again" after a failed update, now ask first in the same confirmation as Settings, Updates, which explains each step of the update. If the update cannot start, the confirmation shows why and stays open. In Settings, Catalogs, an added catalog's Edit and Remove are in a menu beside its switch, and the redundant "Off" badge is gone. A failed refresh shows in red, with its links. The section's button is now "Add catalog", and the keyboard focus goes to it after a catalog is removed. Closing a confirmation without going ahead returns the focus to the button or menu that opened it. Remove Appflare and Rotate auth secret now use the outlined red button that every other delete uses; the solid red is kept for the confirmation itself. Reload, when a new version is slow to answer, is now a button. Running sandbox jobs show the moving Appflare mark instead of a spinner that never turned. Success messages (token rotated, sandbox connected, rollback finished) all look the same and are announced to screen readers. So are the errors in the Remove Appflare dialog and in the sandbox section. The Removed apps buttons name their app for screen readers, and the GitHub access section's empty state takes less room.
