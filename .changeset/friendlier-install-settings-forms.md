The install form and an app's Settings are easier to read. Fields show the app's own labels; the variable or secret name the app reads shows on hover, or next to every label with "Show technical names" at the top of the form. Optional fields say so quietly, long help folds behind "More", each form carries at most one notice at the top, and the build and installer cost confirmations are a checkbox with the details folded away instead of a banner. In Settings, the variables group is now called "Settings", the note on how saving works folds behind "More", and a database's Hyperdrive configuration name shows only with technical names on. Validation messages name a setting by its label only.

Parts of a setting that Appflare fills in (`{{workerUrl}}`, `{{workerName}}`, `{{accountId}}`, `{{wildcardHostname}}`, and `{{workerUrl:<name>}}` and `{{workerName:<name>}}` for the app's own Workers) now show as chips such as "App address" and "Account ID". Hovering, clicking or tapping a chip's name says what it becomes. A chip is removed whole with Backspace or Delete or its × button, cannot be edited in part, and can be added back from the field's Insert menu. The stored value keeps the placeholder, so it follows the Worker name. A placeholder for a Worker the app does not have, and anything else in double braces, stays text.

How to create the Cloudflare API token an app needs for itself now sits next to the field that takes it (a self-deploying app's token field, or the secret the app reads the token from) instead of above the form. After install, Settings shows it next to that secret's new value, or in a section of its own for an app that takes the token in its own setup steps; a self-deploying app shows it on its token card. The app token link now selects every permission the catalog's apps ask for, including Email Routing Rules, Email Routing Addresses, Email Sending, Secrets Store, Firewall Services, Load Balancers, Logs, Magic Transit, R2 Data Catalog and R2 SQL; a permission the link cannot select says why on its own line.
