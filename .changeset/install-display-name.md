Installs can have a display name, such as "Team link shortener". The install form has an optional Name field whose placeholder shows the default, the Worker name, and admins rename an install at any time with the pencil button beside the title of its page; saving an empty name goes back to the Worker name. A name is 1 to 60 characters without line breaks or tabs. When set, the app page's title shows it with the app and Worker names beneath; the home list, the job lists and job pages, pending updates, Update all, the Removed apps list and notification messages all call the install by it. Renaming deploys nothing, and usage data never includes the name. Names given to installs before this version are kept.
